## Tecnologías Utilizadas
- **HTML5:** Estructura semántica del contenido.
- **CSS3:** Estilos personalizados, paleta de colores morado/blanco y animaciones.
- **JavaScript:** Interactividad (scroll suave, validación de formularios, animaciones al hacer scroll).
- **Bootstrap 5:** Framework de diseño para el sistema de grillas (grid), botones, barras de progreso y la barra de navegación responsive.
- **Git y GitHub:** Control de versiones y despliegue web.
